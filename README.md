# GameBOX Fumi

ブラウザーだけで遊べる、日本語のミニゲーム集です。インストールや外部サービスは不要です。

## 遊び方

`index.html` をブラウザーで開き、「プレイ」からゲームを選んでください。タッチ・マウスに対応し、スネークは方向キーでも操作できます。「最初から遊ぶ」で再挑戦、「×」または Escape で一覧に戻れます。

収録ゲーム：神経衰弱、三目並べ、8パズル、ライトアウト、数字当て、じゃんけん、反応速度、もぐらタップ、計算チャレンジ、カラー記憶、スネーク、マインスイーパー。

戦績・ポイント・プレイ時間はブラウザーの localStorage に保存します。ブラウザーや閲覧モードによって保存できない場合があるため、設定画面のバックアップ機能も利用してください。バックアップ読み込み時には現在の戦績が置き換わります。ポイントはこのゲーム集内の記録です。

## 検証

Node.js がある環境で `node tests/games.test.cjs` を実行できます。依存パッケージは不要です。小さな DOM 模型と仮想タイマーで、12ゲームの開始・勝敗・保存・タイマー解除、およびパズル盤面の解答を確認します。ブラウザーでのレイアウト・タッチ操作の検証は別途必要です。
