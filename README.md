# GameBOX Fumi

ブラウザーだけで遊べる、日本語のミニゲーム集です。インストールや外部サービスは不要です。

## 遊び方

`index.html` をブラウザーで開き、「プレイ」からゲームを選んでください。ゲームごとに「かんたん・ふつう・むずかしい」を選んで開始できます。タッチ・マウスに対応し、スネークは方向キーでも操作できます。「最初から遊ぶ」で再挑戦、「×」または Escape で一覧に戻れます。

全100種類を収録しています。通常の99種類に加え、ホームの「Fumiポイント交換所」で500 ptを使うと「秘密のゲーム」が解放されます。ゲームをクリアするとポイントを獲得できます。

戦績・ポイント・秘密のゲームの解放状態・プレイ時間はブラウザーの localStorage に保存します。ブラウザーや閲覧モードによって保存できない場合があるため、設定画面のバックアップ機能も利用してください。バックアップ読み込み時には現在の戦績が置き換わります。ポイントはこのゲーム集内の記録です。

## 検証

Node.js がある環境で `node tests/games.test.cjs` を実行できます。依存パッケージは不要です。小さな DOM 模型と仮想タイマーで、100種類の開始、難易度差、ポイント交換、勝敗・保存・タイマー解除、パズル盤面の解答を確認します。
